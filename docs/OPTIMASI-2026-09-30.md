# Optimasi loading dan output build — 30 September 2026

Dokumen ini mencatat perubahan yang sudah diuji pada mesin lokal. Angka API, ukuran berkas, dan waktu browser memakai metode berbeda; jangan menjumlahkan persentasenya atau menganggapnya sebagai jaminan untuk jaringan produksi.

## Perubahan

- Entry point frontend memuat CSS dan JavaScript rute secara bersamaan. Daftar rute berada di satu tempat agar pemilihan halaman tidak berulang.
- Stylesheet ikon diminta dari HTML dengan koneksi awal ke Google Fonts, sehingga tidak menunggu `@import` di dalam CSS aplikasi.
- Inter hanya menyertakan berkas font Latin yang dipakai antarmuka. Teks dari aksara lain memakai font sistem.
- Build memindahkan aset ke `dist/client` alih-alih menyimpannya dua kali. `npm run preview` dan Docker membaca direktori tersebut.
- Nginx mengaktifkan gzip untuk teks, JavaScript, CSS, JSON, dan SVG. Aset Vite dengan nama berbasis hash mendapat cache satu tahun; dokumen HTML tetap diperiksa ulang.
- Proyeksi peta menghitung jumlah koneksi dan pemasangan aset lewat indeks. Pemilihan geometri jaringan memakai `Set`, sehingga tidak mencari setiap ID di seluruh daftar geometri berulang kali.
- Backend menyimpan hasil pembacaan agregat aktif dan proyeksi katalog aset berdasarkan revisi dataset. Halaman peta dan detail aset memakai hasil yang sama; saat revisi berubah, data dibaca ulang.
- Skrip migrasi kini menjalankan migrasi `0005_topology_interface_registry` yang dibutuhkan backend terbaru.

## Kebersihan kode dan file

- Persiapan identitas, graf, dan katalog aset di backend sekarang berada dalam satu fungsi yang dipakai halaman peta dan detail aset. Kunci cache mencakup revisi dataset, sehingga hasil lama tidak dipakai setelah revisi berubah.
- Dua skrip lint yang mengulang logika sama diganti dengan satu skrip di `shared/lint.mjs`. Pemeriksaan ini memvalidasi sintaks JavaScript; belum memeriksa aturan gaya atau impor yang tidak dipakai.
- Direktori `backend/src/database/database/` dihapus karena berisi 15 salinan file yang tidak diimpor oleh kode atau skrip migrasi. Ukuran totalnya sekitar 50,8 KB.
- `counter.js`, `icons.svg`, dua `.gitkeep` pada direktori yang sudah berisi file, serta `.runtime/map-import-export.png` dihapus setelah pemeriksaan referensi. Gambar runtime tersebut berukuran 44.174 byte.
- `favicon.svg`, `og.png`, dan `icons/junction-box.png` dipertahankan karena digunakan oleh HTML atau kode aplikasi. Laporan audit historis dipertahankan sebagai arsip, bukan bagian dari build aplikasi.

Total **22 file terhapus (101.553 byte)** dibanding Git awal, termasuk dua berkas template dan dua skrip lint yang digabung. Pemeriksaan hash pada file terlacak yang tersisa tidak menemukan pasangan file dengan isi yang sepenuhnya identik. Pemeriksaan ini tidak membuktikan bahwa setiap fungsi atau dokumen historis masih diperlukan.

## Waktu tampil di browser

Tiga navigasi **sebelum backend terbaru dipasang** ke `http://127.0.0.1:5174/map` diukur dengan Edge headless pada 1440 × 900. Cache halaman dimatikan. Semua run menerima HTTP 200 untuk dataset aktif dan menampilkan peta, bukan halaman error. FCP berarti konten pertama terlihat; kanvas MapLibre berarti area peta sudah dibuat; status basemap tersedia berarti tile dari layanan luar mulai berhasil dimuat.

Lighthouse desktop menghasilkan median FCP **807 ms**, LCP **966 ms**, Speed Index **2.804 ms**, Time to Interactive **2.341 ms**, dan skor performa **74/100** dari tiga run. Filmstrip menunjukkan LCP tersebut terjadi saat status “Memuat dataset aktif” masih tampil, sehingga LCP tidak boleh dibaca sebagai waktu peta selesai. Kanvas menunjukkan peta mulai dibuat; status basemap dipengaruhi pengambilan tile dan lebih bervariasi. Ini pengukuran lokal, bukan data pengguna di jaringan produksi.

Setelah backend terbaru dipasang, satu navigasi tambahan menghasilkan FCP **832 ms**, kerangka peta **1.427 ms**, dan kanvas peta **1.445 ms**. Ini satu sampel, sehingga belum cukup untuk menyatakan persentase peningkatan waktu browser. Basemap eksternal masih berstatus memuat setelah 12 detik pada sampel tersebut; kelambatannya belum terselesaikan. Aset dan geometri lokal tetap dapat tampil saat tile luar tertunda.

## Verifikasi

### Perbaikan lanjutan pemuatan ikon dan overlay

Pengambilan satu ikon KMZ berukuran 7.911 byte sebelumnya memerlukan 7,70 detik.
Endpoint gambar membaca agregat dataset lengkap untuk setiap permintaan. Kini
PostgreSQL hanya mengambil metadata sumber yang diperlukan, sedangkan penyimpanan
JSON memakai cache manifest maksimal empat versi. Permintaan bersamaan berbagi
satu pembacaan; perubahan identitas, ukuran, atau waktu file membatalkan cache.
Pemeriksaan autentikasi dan integritas paket KMZ tetap dijalankan.

Gambar cakupan CCTV sekarang dimuat ketika pengguna mengaktifkan cakupannya.
Pengujian browser menemukan 0 permintaan overlay saat awal dan gambar berhasil
diambil setelah tombol diaktifkan. Gambar tetap berada di bawah lapisan aset.
