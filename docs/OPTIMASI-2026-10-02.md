# Ikon aset dan optimasi pemuatan — 2 Oktober 2026

Perubahan ini mencakup ikon aset, proyeksi dataset aktif, dan basemap Jalan & bangunan. Angka berikut berasal dari pengujian Docker/PostgreSQL lokal menggunakan dataset yang sama. Waktu API dan resource terpisah dari waktu seluruh peta selesai dirender.

## Ikon aset

Pengguna dapat mengganti ikon dari bagian atas panel detail aset, melihat pratinjau, dan kembali ke ikon bawaan. Gambar dinormalisasi menjadi PNG sebelum disimpan. Peta dan diagram memakai ikon yang sama, termasuk aset dari kategori baru hasil impor KMZ. API memeriksa akses cabang, versi dataset, dan revisi sebelum menyimpan perubahan.

## Dataset aktif

| Pengukuran | Sebelum | Sesudah |

| Respons JSON peta | 34,634 MB | 7,151 MB |

| API pertama setelah restart dengan cache/revisi cocok | Cache hilang saat restart | 0,247 detik |

Endpoint peta tidak lagi mengirim arsip internal mesin identitas/topologi. PostgreSQL menyiapkan proyeksi operasional dan peta dalam transaksi yang sama dengan agregat sumber; detail dan tracing tetap memperoleh data yang diperlukan. Pembacaan proyeksi memeriksa versi proyektor, konteks cabang, pointer publikasi, dan `xmin` agregat. Perubahan eksternal membatalkan kecocokan cache.

Dataset lama menyiapkan proyeksi sekali bila belum tersedia; pada sampel ini persiapan awal membutuhkan 6,486 detik. Cache respons dibatasi 96 MiB/16 file, memvalidasi integritas dan revisi, serta bertahan setelah restart. Migrasi `0007` dan `0008` menyediakan penyimpanan proyeksi baca.

## Basemap

Sampel tile OpenFreeMap yang sama, z=14/x=13217/y=8511:

| Pengukuran | Sebelum | Sesudah |
| --- | ---: | ---: |
| Permintaan ulang tile tanpa cache klien | 696 ms | 48–87 ms melalui cache memori |
| Pertama setelah restart/pembuatan ulang container | Mengambil ulang dari provider | 72–128 ms melalui cache disk |
| Ukuran transfer tile | 370.493 byte | 233.212 byte, turun 37% |
| Ukuran transfer font label | 76.580 byte | 42.482 byte, turun 45% |

Metadata dan font mulai dimuat bersamaan dengan dataset. Kamera awal langsung memakai batas area. Proxy menggabungkan permintaan resource yang sama, menyimpan hasil di memori/disk, dan mendukung gzip serta ETag. URL tile menyertakan snapshot provider agar cache browser tidak mencampur versi basemap.

Cache basemap dibatasi 32 MiB memori dan 128 MiB/512 resource di disk. Metadata memiliki masa cache 6 jam; tile/font 7 hari di server. Cache rusak atau kedaluwarsa diambil ulang. Permintaan pertama untuk resource yang belum tersimpan masih bergantung provider; dalam pengukuran ini metadata pertama 2,343 detik dan tile pertama 803 ms. Citra satelit memakai provider Esri dan tidak masuk pengukuran ini.

## Verifikasi

Tes mencakup persistensi proyeksi, perubahan/aktivasi dataset, invalidasi cache setelah perubahan eksternal, penggantian ikon, gzip/ETag, pergantian snapshot, dan penggabungan download saat cache penuh. Pengujian PostgreSQL memakai fixture terisolasi. Pengecekan UI memastikan aset, jalur, ikon, jalan, dan bangunan tampil pada dataset aktif.
